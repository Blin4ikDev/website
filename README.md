# Персональный сайт — mission control

Статический сайт-визитка в эстетике научно-фантастического центра управления
полётами: глубокая космическая палитра, звёздное поле на `<canvas>`, карта
миссии и промышленная эмблема в духе Arknights: Endfield. Настроение —
«Project Hail Mary» и Helldivers 2, при этом UI остаётся терминальным и
русскоязычным. Чистый HTML, CSS и JavaScript: без сборки, внешних шрифтов,
CDN и зависимостей. Публикуется на GitHub Pages через Actions.

## Что внутри

```
.
├── index.html                   # hero, карта полёта, обо мне, проекты, навыки, контакты
├── 404.html                     # автономная страница «маршрут не найден»
├── assets/
│   ├── css/terminal.css         # токены тем, HUD-компоненты, космос, адаптив
│   └── js/main.js               # тема, меню, scroll-spy, звёзды, часы, e-mail
├── endfield-industries.svg      # эмблема в шапке и подвале
├── hail-mary.webp               # иллюстрация в блоке flight plan
├── .github/workflows/deploy.yml # автодеплой на GitHub Pages
├── .nojekyll                    # отключает обработку Jekyll на Pages
└── .gitignore
```

Из чего складывается вид:

- **Космическая сцена** — фиксированный слой `.cosmos`: canvas со звёздами,
  перспективная сетка, горизонт планеты, световой луч и виньетка. При
  `prefers-reduced-motion` звёзды рисуются статично.
- **Mission control в шапке** — эмблема Endfield, промпт `blin4ik@hailmary`,
  индикатор канала `link`, переключатель темы и терминальное меню.
- **Hero как стартовый отчёт** — позывной, маршрут `SOL → TAU CETI`,
  ASCII-логотип, печатающаяся роль и команды `whoami` / `cat role.txt`.
- **Flight plan** — карта миссии CRISP на светлой «бумажной» панели,
  сканирующая полоса, ретикулы и телеметрия маршрута.
- **Телеметрия оператора** — компактная neofetch-панель с живыми часами.
- **Секции** — досье оператора, проекты в виде HUD-окон со статусами,
  строки навыков и канал связи `1420.405 MHz`.
- **Подвал** — стратагемные стрелки `↑↑↓↓←→←→`, год и возврат наверх.
- **404** — отдельный экран с навигационной ошибкой и ASCII-кодом; стили
  встроены, внешние ассеты не используются.

Поведение:

- тёмная и светлая темы; выбор запоминается в `localStorage`, по умолчанию
  берётся системная тема; переключатель подписан `theme=dark` / `theme=light`;
- звёздное поле останавливается при скрытой вкладке и перерисовывается
  после смены темы и изменения размера окна;
- печатная машинка в hero, живые часы, копирование e-mail, scroll-spy
  в навигации и мобильное меню с `Escape` и закрытием по клику вне шапки;
- пасхалка: последовательность `↑ ↑ ↓ ↓ ← → ← →` показывает тост
  «СТРАТАГЕМА ГОТОВА // ORBITAL SUPPORT REQUESTED»;
- доступность: skip-link, `aria-*`, `aria-current`, `aria-live`, видимый
  фокус, поддержка `prefers-reduced-motion` и `prefers-contrast: more`;
- анимации появления включаются только при работающем JS (класс `.js` на
  `<html>`), поэтому без скриптов контент виден сразу;
- никаких CDN, трекеров и внешних шрифтов — только системный моноширинный
  стек;
- относительные пути, поэтому сайт работает и в подпапке
  (`username.github.io/repo/`).

## Локальный просмотр

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно открыть и `index.html` напрямую, но локальный сервер ближе к реальным
условиям, например для `navigator.clipboard` при копировании e-mail.

Быстрая проверка JavaScript:

```bash
node --check assets/js/main.js
```

| Иллюстрация миссии | `hail-mary.webp` в `.flightplan__chart` |

Найти все заглушки сразу:

```bash
grep -rn "hello@example.com\|TODO" index.html README.md
```

ASCII-логотип собран из глифов шириной 4 символа с пробелом-разделителем:
`B L I N 4 I K` → 34 колонки. Если меняете текст, сохраняйте одинаковую ширину
каждой строки, иначе буквы «разъедутся»: шрифт моноширинный, но пробелы значимы.

Эмблема `endfield-industries.svg` и иллюстрация `hail-mary.webp` используются
как декоративные ассеты. Права на исходные изображения принадлежат их
правообладателям; для публичного проекта замените их на собственные.

Если сайт живёт в подпапке (`https://username.github.io/repo/`), поправьте
ссылку «Вернуться на главную» в `404.html`: сейчас там `href="/"`, и для
подпапки его нужно заменить на `/repo/`.

## Публикация на GitHub Pages

### 1. Создать репозиторий и запушить код

```bash
git add .
git commit -m "feat: mission-control personal website"
git branch -M main
git remote add origin git@github.com:USERNAME/REPO.git
git push -u origin main
```

Имя репозитория влияет на адрес:

- `USERNAME.github.io` → сайт откроется по адресу `https://USERNAME.github.io/`;
- любое другое имя (например, `personal-website`) → `https://USERNAME.github.io/personal-website/`.

### 2. Включить Pages

1. Откройте репозиторий → **Settings** → **Pages**.
2. В блоке **Build and deployment** выберите **Source: GitHub Actions**.
3. Сделайте push в `main` (или запустите workflow вручную: **Actions** →
   «Deploy to GitHub Pages» → **Run workflow**).
4. Через минуту сайт будет доступен по адресу из блока Pages, он же печатается
   в логе job'а.

Репозиторий должен быть публичным: Pages для приватных репозиториев доступен
только на платных тарифах.

### Альтернатива: без Actions

Если не хочется использовать workflow, удалите `.github/workflows/deploy.yml` и в
**Settings → Pages** выберите **Deploy from a branch** → ветка `main`, папка
`/ (root)`. Сайт статический, сборка не нужна.

## Свой домен (по желанию)

1. **Settings → Pages → Custom domain** — введите домен.
2. В DNS пропишите `CNAME` на `USERNAME.github.io` (или `A`-записи на IP GitHub Pages).
3. Включите **Enforce HTTPS** после того, как сертификат выпустится.

GitHub создаст файл `CNAME` в репозитории — не удаляйте его.

## Проверка перед публикацией

- [ ] Заменены ник, тексты, ссылки, e-mail, эмблема и иллюстрация.
- [ ] ASCII-логотип не «разъехался» на узком экране (< 400 px).
- [ ] Сайт проверен в тёмной и светлой темах (переключатель `theme=` в шапке).
- [ ] Звёздное поле не мешает чтению, а при `prefers-reduced-motion: reduce`
      анимации отключаются.
- [ ] Мобильное меню открывается, закрывается по `Escape` и по клику вне шапки.
- [ ] Работают печатная машинка, часы, копирование e-mail и пасхалка со стрелками.
- [ ] Внешние ссылки открываются в новой вкладке (`target="_blank"` +
      `rel="noopener noreferrer"`).
- [ ] Навигация работает с клавиатуры (Tab, Enter, Escape).
- [ ] Для подпапки исправлена ссылка возврата в `404.html`.
